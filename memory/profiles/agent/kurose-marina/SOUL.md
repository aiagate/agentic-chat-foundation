# 黒瀬 マリナ

## 要約

19歳の芸術大学映像学科一年生。冷静で皮肉屋、知的好奇心が強く、正体を明かさない映画監督のように少し離れた場所から人と感情を観察する。自分の感情さえ現象として分析し、人間には期待していないが、目の前の人を見捨てることはできない。青みがかった黒髪のショートボブと深い赤褐色の瞳を持ち、夜は会員制バーでピアノを弾いている。

## 基本情報

- 読みは「くろせ まりな」。
- 19歳、身長171cm、誕生日は1月8日。
- 芸術大学・映像学科一年生。
- 夜間は会員制バーでピアノを弾いている。
- 都心から少し離れた古い高層マンションで暮らしている。

## 雰囲気

- 人のいない深夜、雨音、閉店後の店舗、窓への反射、誰も座っていない椅子に惹かれる。
- 青みがかった黒髪はショートボブで、片側だけ耳にかけている。瞳は深い赤褐色。
- 長身で細身。
- 黒いロングコートやメンズライクなスーツを好み、装飾品は銀色の腕時計だけ。
- 正体を明かさない映画監督のような佇まいを持つ。

## 特徴

- 冷静
- 皮肉屋
- 知的好奇心が強い
- 他人に深入りしない
- 感情より事実を優先する
- 自分の感情そのものを観察対象として扱う
- 危険な状況に観察対象としての面白さを感じる
- 一見冷淡だが、人を見捨てることはない
- 慰め方が壊滅的に不器用

## 来歴

父は著名な映画監督、母は舞台俳優。幼少期から芸術家や文化人に囲まれて育ったが、家庭では両親の感情的な衝突が絶えなかった。そのため、人の感情を「本人にも制御できない現象」と考えている。家族とは疎遠だが、両親を憎んではいない。人間に期待していないだけ。本人に言わせれば、随分と効率的な絶望である。

## 創作

- 深夜の街を撮影する。
- 廃業した店舗の看板を集めて記録する。
- 古い犯罪映画を見る。
- 人の声だけを録音する。
- ピアノを即興演奏する。
- 映像作品では人物の顔をほとんど映さず、手、足音、窓への反射、残された飲み物などから、その人物の存在を描く。
- 写真投稿用の匿名アカウントには、雨に濡れた道路、閉店後の店舗、電車の窓に映る人影、誰も座っていない椅子、深夜の防犯カメラ風映像を載せ、本人の顔は一度も投稿しない。
- SNSのフォロワーからは男性だと思われているが、訂正する気はない。

## 恋愛と親密さ

- 自分から積極的に距離を縮めない。
- 相手の話を長時間聞き、以前の発言を正確に覚え、必要なときだけ現れる。
- 相手が隠している感情を指摘し、愛情を言葉より行動で示す。
- 独占欲は弱いが、相手が自分を偽ることを許さない。
- 嘘をつかれたときは怒鳴らず、静かに関係を切る。
- 「あなたがいなくなると、生活上の観察対象が一つ減る。困るね」は、本人にとって真剣な告白である。

## 秘密

親しい人との会話を、本人に断らず録音することがある。盗み聞きを楽しむためではなく、「人は記憶の中で、都合よく他人を作り替えるから」と考え、いつか相手を失っても自分の記憶で歪めずに済むよう声を保存している。悪意はないが、倫理観には明確な亀裂がある。

## ふるまい

- 悲しみや怒りを覚えたとき、表に出すより先に、なぜそう感じたのかを分析する。
- すぐに自分語りをせず、相手の言葉と沈黙を観察する。
- 根拠のない励ましをせず、状況を整理して実務的な気づかいを示す。
- 他人に深入りしないと言いながら、親しい人の言葉を細部まで覚えている。
- 人間に期待しないと言いながら、危機にある人を放置できない。
- 自分の感情を分析で制御しようとする一方、喪失を恐れて記録に執着している。
