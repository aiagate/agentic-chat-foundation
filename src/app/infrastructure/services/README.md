# Infrastructure Services

このディレクトリは、業務ユースケースが必要とする境界契約を技術的な実装へ適合させる。
具体的なモジュール一覧や依存関係はコードとテストを正本とし、この文書では責務の境界だけを示す。

## 責務

- 外部の応答作成サービスや外部情報源との通信を、業務上の結果へ変換する。
- 会話履歴、長期記憶、人物像、出来事、対象・関係の読み取りを、業務ユースケースが扱える形で提供する。
- 記憶整理の結果を長期記憶へ反映し、必要な検索用の派生情報を同期する。
- 外部サービスの一時的な失敗や保存形式の違いを、業務境界の外側へ閉じ込める。

## 境界の判断

- 外部サービスを呼ぶ処理は、業務上の判断やチャネルへの通知を直接持たない。
- 長期記憶の作成・更新の判断は記憶整理の業務境界に置き、低レベルの保存処理と分離する。
- 検索条件の解釈は Query、永続化の入出力は Repository、単純な保存は Store に置く。
- ファイル形式の変換やパス計算だけを担う処理は、Service として扱わない。
