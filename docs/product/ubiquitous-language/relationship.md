# 用語

| 用語 | 意味 |
|---|---|
| キャラクター | 利用者と対話する人格・役割の単位。同じ利用者でもキャラクターが異なれば会話履歴と関係状態を共有しない。 |
| 関係状態 | 一人の利用者と一人のキャラクターの交流から形成される状態。好感度とその更新履歴を含む。 |
| 好感度 | 関係状態の進行を `0` から `100` で表した整数。人物像や長期記憶とは別の正本を持つ。 |
| 関係段階 | 好感度を共通の8区間へ写像した状態。キャラクターが変わっても区間は共通で、表現方針はキャラクターごとに異なる。 |
| 関係シグナル | 会話が関係状態へ与える意味を、強い低下・低下・中立・上昇・強い上昇のいずれかで表した評価候補。 |
| 暫定シグナル | 応答を待たせないため、会話と並行して評価し、次回応答から利用できる関係シグナル。 |
| 確定シグナル | 日次の会話履歴整理で会話全体を根拠として再評価され、暫定シグナルを置き換えた関係シグナル。 |
| 根拠会話 | 関係シグナルの判断を直接支える一件以上の会話メッセージ。 |
| 関係行動コンテキスト | 現在の関係段階に応じてアプリケーションが選び、応答作成へ一時的に渡す追加方針。 |
| キャラクター関係定義 | 各関係段階で利用可能な関係行動コンテキストと重みを定義する、キャラクター固有の不変設定。 |

# 共通の関係段階

| ID | 好感度 | 業務上の位置づけ |
|---|---:|---|
| `distant` | 0–10 | 距離がある |
| `recognized` | 11–25 | 相手を認識している |
| `interested` | 26–40 | 相手へ関心がある |
| `affectionate` | 41–55 | 好意を持っている |
| `trusting` | 56–70 | 相手を信頼している |
| `intimate` | 71–85 | 親密な関係にある |
| `attached` | 86–95 | 強く愛着を持っている |
| `devoted` | 96–100 | 深い献身を示す |

段階IDや数値は内部状態であり、通常の会話では利用者へ明かさない。段階が上がっても人格そのものを
別人へ変えず、現在の人格へ一時的な行動方針を加える。

# 責務境界

- AIは会話から関係シグナル候補を評価できるが、今回の応答で使う関係段階や関係行動コンテキストを選ばない。
- 関係段階の解決と関係行動コンテキストの抽選は、保存済み好感度とキャラクター関係定義を使ってアプリケーションが行う。
- 関係行動コンテキストは人格・安全制約より低い優先度であり、外部機能を実行した事実を作り出さない。
- 好感度は長期記憶のRelationship Entity、人物像のscore、会話文からの都度推測を正本にしない。
