# 用語

| 用語 | 意味 |
|---|---|
| 利用者 | システムと対話し、その会話履歴と長期記憶の所有者となる人。 |
| チャネル | 利用者がメッセージを送り、応答を受け取る外部の会話手段。 |
| チャネル上の利用者識別子 | チャネルが利用者を識別するために発行する識別子。業務上の利用者とは別の概念である。 |
| 会話 | 一人の利用者、一人のキャラクター、一つのチャネル上の外部会話endpointで継続する一対一のやり取り。キャラクター、チャネル、外部会話endpointのいずれかが異なる会話は別の履歴として扱う。 |
| 会話メッセージ | 利用者または対話相手が会話へ加えた一件のメッセージ。 |
| 会話履歴 | 会話メッセージを、意味を変えずに時系列で保持した記録。 |
| 受付済みメッセージ | 正しい利用者と会話に関連付けられ、応答作成の対象として確定したメッセージ。 |
| 応答結果 | 受付済みメッセージに対して作成された、利用者へ届ける一つの論理的な結果。 |
| 応答不能 | 応答を作成または届けられないことが確定した結果。 |

チャネルをまたぐ長期記憶はcanonical User単位で共有するが、短期の会話履歴はチャネル上の外部会話単位で分離する。
