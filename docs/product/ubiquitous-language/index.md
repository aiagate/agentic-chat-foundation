# ユビキタス言語バンドル

このディレクトリは、会話、長期記憶、キャラクターとの関係状態を説明するときに使う業務上の言葉を表す OKF v0.1 バンドルである。
コード上の型名、保存形式、外部サービスの名称は、このバンドルで定義する業務上の概念を実現する手段であり、
業務上の概念そのものではない。

## 読み方

- [利用者と会話](/conversation.md)
- [外部情報と長期記憶](/memory.md)
- [対話相手との関係状態](/relationship.md)
- [業務上の原則](/principles.md)
- [ユースケース知識バンドル](../application-use-cases/index.md)

## 正本の関係

業務上の意味はこのバンドルと[ユースケース知識バンドル](../application-use-cases/index.md)で定義する。
保存形式や実装上の振る舞いは、[Memory Markdown Schema](../../infrastructure/memory-markdown-schema/index.md)などの
技術リファレンスを参照する。
