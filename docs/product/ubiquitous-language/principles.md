# 原則

- チャネル上の利用者識別子は、対応付けが確認できた場合だけ利用者の会話と長期記憶へ結び付ける。
- 会話履歴は記録であり、長期記憶は意味を整理した結果である。
- 長期記憶は根拠と不確実性を伴い、根拠を確認できない内容は確定しない。
- 外部情報は現在の応答の根拠として扱い、取得しただけで長期記憶へ加えない。
- 一人の利用者に属する会話履歴、長期記憶、参照結果は、別の利用者の境界を越えない。
- 会話履歴と関係状態はキャラクター境界を越えず、同じ利用者の別キャラクターへ混入させない。
- 関係状態は根拠会話から更新し、応答の文体だけを根拠に自己増殖させない。
- 関係行動はAIの自由判断ではなく、保存済み関係状態から選ばれたコンテキストによって切り替える。
