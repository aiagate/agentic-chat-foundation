# プロジェクトの目的

利用者が1対1のテキスト会話を通じて、役割や人格を持つキャラクターと継続的に対話し、
交流の積み重ねに応じた関係変化を体験できることを目的とする。

システムは、現在の会話、過去の交流から整理された長期記憶、必要に応じて取得した外部情報を用いて
応答を作成する。会話履歴はそのままの記録として保持し、長期記憶は将来の対話に有用な意味だけを
周期的に整理する。キャラクターとの関係状態は長期記憶とは別に保持し、保存済み状態に応じて
アプリケーションが応答用コンテキストを切り替える。

ユースケースは、アクターにとって意味のある結果を生む業務フローとして記述する。
既存のクラス、処理名、データ構造、実行環境は能力を発見するための材料としてのみ扱い、
目標設計の前提にしない。内部状態、メッセージ配送方式、再試行方式、保存形式は本バンドルの対象外とする。

用語は[ユビキタス言語バンドル](../ubiquitous-language/index.md)で定義する。

# アクター

## 主要アクター

### 利用者

会話チャネルを通じてシステムへメッセージを送り、応答を受け取る人。
チャネル上の利用者識別子と、業務上の利用者の同一性は別の概念として扱う。

### システム

メッセージを受け付け、会話文脈と関係行動コンテキストを組み立て、応答を作成し、会話履歴を整理する対話システム。
利用者の操作を直接の起点としない周期処理も、システムの業務として扱う。

## 補助アクター

### 会話チャネル

利用者のメッセージをシステムへ渡し、システムの結果を利用者へ届ける外部サービス。

### 外部情報源

システムからの問い合わせに対し、システム内にない情報や現在性のある情報を返す外部サービス。

### 時間

長期記憶と確定関係シグナルの整理を開始する時間経過または定期的な契機。
