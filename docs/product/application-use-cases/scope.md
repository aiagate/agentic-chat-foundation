# 対象

- 外部の会話チャネルを通じた1対1のテキスト会話
- 利用者のメッセージの受信、記録、応答、結果の通知
- 応答に必要な外部情報の一時的な取得
- 会話履歴を用いた文脈の継続
- キャラクターと利用者の組ごとの好感度、関係段階、応答行動コンテキストの切り替え
- 人物像、出来事、対象・関係の長期記憶の生成・更新・参照
- チャネル上の利用者識別子を一人の利用者へ明示的に対応付けること
- 応答処理や会話履歴整理の失敗を、失敗結果として確定すること

# 対象外

- 組織、チーム、メンバーシップの管理
- 対話目的とは独立した利用者・組織管理機能
- 利用者登録・チャネル上の利用者識別子の対応付けを利用者自身が行う機能
- グループ会話、ルーム会話、複数利用者間の調整
- 画像、スタンプ、音声などの非テキスト入力
- 利用者から開始されない自発的な通知や外部操作
- 好感度によるツール解禁、ローカルネットワーク探索、撮影・録音・訪問・監視の実行
- 好感度以外の育成パラメーターと、実行中の動的キャラクター切り替え
- 利用者の要求とは独立した未完了処理の自動回復や永続的な処理待ち
- 特定の AI モデル、データベース、キュー、ファイル形式、プロセス構成

# 別Bounded Context

Discord公開議論は、上記の1対1会話core domainとは別の任意機能として扱う。
公開チャンネル上の複数参加者、Botごとのローカル評価状態、自発的な話題生成を対象とし、
canonical User、1対1会話の短期履歴、長期記憶、CharacterRelationshipは共有しない。
業務上のスコープ、アクター、完了状態は[Discord公開議論バンドル](../discussion/index.md)で定義する。
