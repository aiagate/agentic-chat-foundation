# 利用者の能力

| ID | ハイレベルユースケース |
|---|---|
| HL-U01 | 利用者は、会話チャネルからシステムへメッセージを送信できる。 |
| HL-U02 | 利用者は、現在の会話に沿った応答を受け取ることができる。 |
| HL-U03 | 利用者は、過去の交流を反映した継続的な対話ができる。 |
| HL-U04 | 利用者は、応答できない場合に、その結果を認識できる。 |
| HL-U05 | 利用者は、キャラクターとの交流の積み重ねに応じた一貫した行動変化を体験できる。 |

# システムの能力

| ID | ハイレベルユースケース |
|---|---|
| HL-S01 | システムは、利用者からのメッセージを受信し、会話履歴として記録できる。 |
| HL-S02 | システムは、メッセージを正しい利用者と会話に関連付け、応答対象にできる。 |
| HL-S03 | システムは、現在の会話と関連する長期記憶を使って応答を作成できる。 |
| HL-S04 | システムは、必要な場合に外部情報を取得し、応答へ反映できる。 |
| HL-S05 | システムは、生成した応答または応答不能の結果を元の会話へ届けられる。 |
| HL-S06 | システムは、会話から人物像、出来事、対象・関係の長期記憶を生成・更新できる。 |
| HL-S07 | システムは、利用者ごとの会話履歴と長期記憶を分離して扱える。 |
| HL-S08 | システムは、キャラクターと利用者の組ごとに関係状態を保持し、現在状態に対応する応答コンテキストを選択できる。 |
| HL-S09 | システムは、会話から暫定・確定関係シグナルを得て、同じ根拠を二重計上せず関係状態を更新できる。 |

# 粒度の判断

- チャネルごとの受信は、「メッセージを受け付ける」の入口の違いとして扱う。
- 会話履歴の参照、長期記憶の参照、外部情報の取得は、「会話への応答を作成する」内の判断・補助フローとする。
- 応答の文面を作る処理と、必要な補助情報を集める処理を別の利用者向けユースケースに分けない。
- 応答不能は独立したユースケースにせず、「会話への応答を作成する」または「応答結果を利用者へ届ける」の例外結果とする。
- 長期記憶と確定関係シグナルの整理は、利用者の応答とは異なる時間起点を持つため、「会話履歴を整理する」として分ける。
- 未完了処理の再実行、処理待ち、派生情報の再構築は業務ユースケースとして定義しない。
