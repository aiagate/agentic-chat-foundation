# 目的

キャラクターと利用者の組に属する未処理会話から、将来の対話に有用な長期記憶と確定関係シグナルを
一度に抽出する。暫定シグナルを確定結果へ置き換え、同じ根拠を二重計上せず関係状態を再計算する。

# アクター

## 主要アクター

システム

## 補助アクター

時間

# 起点

定期的な会話履歴整理の契機に、前日までの未処理会話を確認する。

# 事前条件

- 対象キャラクターと利用者を特定できる。
- 対象キャラクターに属する未処理会話が存在する。
- 既存の長期記憶と関係状態を比較対象として参照できる。
- 各会話を根拠IDと観測時点によって識別できる。

# 基本フロー

1. システムが、一つのキャラクターと一人の利用者に属する、JST日単位の未処理会話を選ぶ。
2. システムが、対象会話を一度の意味抽出へ渡し、次の候補と全会話の評価を得る。
   1. 安定した特徴、嗜好、長期的な制約を表す人物像。
   2. 出来事、経緯、結果、反応を表す記憶。
   3. 人物、物事、計画、その属性や対象間の関係。
   4. キャラクターと利用者の関係を変化させる確定関係シグナル。
3. システムが、各候補へ根拠会話、不確実性、観測時点を関連付ける。
4. システムが、長期記憶候補を既存記憶と比較し、新規作成、更新、統合、変更なし、保留を判断する。
5. システムが、基準を満たす非中立の確定関係シグナルを選ぶ。
6. システムが、評価対象会話と重なる暫定・旧確定シグナルを置換対象とし、新しい確定シグナルを登録する。
7. システムが、有効な全関係シグナルを観測時点とIDの順に適用し、日次増減上限と `0`–`100` の範囲を適用して関係状態を再計算する。
8. システムが、利用者・キャラクター境界、根拠、重複、矛盾を確認する。
9. システムが長期記憶更新を適用し、続いて関係状態更新と対象会話の処理済み記録を同じ永続化単位で確定する。

# 代替・例外フロー

## A1. 長期記憶に値する内容がなかった

1. システムが長期記憶を生成しない。
2. 確定関係シグナルがあれば、関係状態更新だけを同じ完了単位で確定する。
3. どちらの更新も不要なら、対象会話の評価だけを処理済みとして確定する。

## A2. 関係を変化させる根拠がなかった

1. システムが中立の評価を好感度へ適用しない。
2. 長期記憶更新があれば、それだけを確定する。
3. 対象会話と重なる誤った暫定シグナルがある場合は、確定結果によって置換する。

## A3. 既存の長期記憶と重複した

1. システムが同じ内容の記憶を増やさない。
2. 新しい根拠や観測時点が有用な場合だけ既存記憶を更新する。

## A4. 既存の長期記憶と矛盾した

1. システムが、誤った情報の訂正か、時間経過による状態変化かを確認する。
2. 訂正なら、誤っていた旧値を残さず現在値へ置き換える。
3. 時間変化なら、以前の状態と観測時点を履歴として残す。
4. 判断できない場合は確定せず、次回へ保留する。

## A5. 同じ根拠の確定関係シグナルが訂正された

1. システムが旧確定シグナルを置換済みとする。
2. 新しい確定シグナルを登録する。
3. 現在値への差分適用ではなく、全有効シグナルから関係状態を再計算する。

## A6. 根拠、利用者、キャラクターを確認できなかった

1. システムが、その候補を長期記憶または関係シグナルとして確定しない。
2. 対象会話を処理済みとせず、次回以降に再評価可能な状態とする。

## A7. 長期記憶更新または関係状態更新に失敗した

1. システムが、対象会話を処理済みにしない。
2. 対象会話を完了扱いにせず、その回の整理を失敗として終了する。
3. 同じ対象範囲を再実行し、冪等な長期記憶更新と関係シグナル照合を再適用できるようにする。

## A8. 関係状態のversionが競合した

1. システムが古いversionを前提とした関係状態更新を確定しない。
2. 対象会話を処理済みにせず、最新状態を読み直せる再実行対象として残す。

# 成功時の事後条件

- 有用な人物像、出来事、対象・関係の記憶が生成または更新されている。
- 基準を満たす確定関係シグナルが根拠会話とともに保存されている。
- 対象会話と重なる暫定・旧確定シグナルは置換され、好感度へ二重計上されていない。
- 好感度は有効な全シグナル、JST日次上限、値域を使って再計算されている。
- 各記憶と関係シグナルから根拠会話と観測時点を追跡できる。
- 長期記憶更新が完了し、関係状態と処理済み記録が同じDBトランザクションで確定している。
- 元の会話履歴は、長期記憶と関係状態とは別の根拠として保持されている。

# 最低保証

別の利用者またはキャラクターの会話・記憶・関係状態は参照・変更されない。整理を完了できなかった会話は
処理済みとされず、不完全な長期記憶や関係状態を成功結果として確定しない。
