# 目的

確定した応答または応答不能の結果を、元の会話の利用者へ届ける。

# アクター

## 主要アクター

システム

## 補助アクター

会話チャネル

# 起点

[会話への応答を作成する](/use-cases/create-conversation-response.md) で応答結果または
応答不能の結果が確定する。

# 事前条件

- 対象利用者と元の会話が特定されている。
- 利用者へ提示する内容が確定している。

# 基本フロー

1. システムが、受付時に確定した会話を配送先とする。
2. システムが、結果を会話チャネルで提示可能な形に整える。
3. システムが、結果を会話チャネルへ渡す。
4. 会話チャネルが、結果を利用者へ届ける。
5. システムが、提示した内容と結果を受付済みメッセージと同じキャラクターの会話履歴へ記録する。

# 代替・例外フロー

## A1. 会話チャネルへ届けられなかった

1. システムが、送達不能の結果として処理を終了する。
2. 自動再送や別チャネルへの切り替えは行わない。

## A2. 応答不能の結果だった

1. システムが、応答できなかった理由を利用者へ提示可能な範囲で示す。
2. 応答不能の結果を会話履歴へ記録する。

# 成功時の事後条件

- 利用者が応答または応答不能の結果を受け取っている。
- 結果が会話履歴へ反映されている。

# 最低保証

送達を確認できない結果を、送達済みとして扱わない。
