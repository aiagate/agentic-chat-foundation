# 規則

| ID | 業務規則 |
|---|---|
| BR-01 | 一つのメッセージは、利用者、キャラクター、チャネル上の外部会話endpointから定まる一つの会話へ関連付けられる。 |
| BR-02 | 正常処理では、一つの利用者メッセージから一つの論理的な応答結果を作る。 |
| BR-03 | 同じ会話のメッセージは論理的な順序で扱い、後続メッセージを先行処理の文脈へ混入させない。 |
| BR-04 | 応答の宛先は受付時の会話で決まり、応答作成側が任意に選ばない。 |
| BR-05 | 外部情報は現在の応答の一時的な根拠であり、長期記憶へ自動的に昇格しない。 |
| BR-06 | 会話履歴は変更していない記録、長期記憶は意味を抽出した整理結果として扱う。 |
| BR-07 | 人物像は安定した特徴、出来事は時間を伴う経験、対象・関係は人物や物事の状態を表す。 |
| BR-08 | 会話履歴、長期記憶、参照結果は利用者の境界を越えない。複数チャネルの識別子を同じ利用者へ結び付けた場合、長期記憶は同じUser境界に属する。 |
| BR-09 | 不確実な記憶は事実として補完せず、根拠と不確実性を保持する。 |
| BR-10 | 失敗した処理はその場で失敗として確定し、未完了の処理を成功として扱わない。 |
| BR-11 | 会話履歴、関係状態、関係シグナルは利用者とキャラクターの組を越えて共有しない。会話履歴はさらにチャネル上の外部会話endpointで分離する。 |
| BR-12 | 今回の応答は応答作成開始時点の関係状態を使い、今回の会話から得た暫定シグナルは次回の応答から反映する。 |
| BR-13 | 関係段階と関係行動コンテキストはアプリケーションが決定し、AIへ選択させない。 |
| BR-14 | 中立または信頼度が基準未満の関係シグナルは好感度を変更しない。 |
| BR-15 | 同じ根拠会話の再評価は旧シグナルを置き換え、好感度へ二重計上しない。 |
| BR-16 | 関係行動コンテキストは人格と安全制約を上書きせず、実行していない外部操作を実行済みとして語らせない。 |
| BR-17 | 長期記憶はUser単位でキャラクター間に共有するが、raw chatの根拠には元の`character_id`を保持し、関係状態や関係行動を長期記憶へ保存しない。 |
