# 未決定事項

- 利用者が長期記憶を閲覧、訂正、削除できるか。
- 会話履歴と長期記憶をどの期間保持するか。
- 利用者自身がチャネル上の利用者識別子の対応付けを登録・変更できる機能を提供するか。
- 応答不能時に別の通知方法を提供するか。
- グループ会話、メディア入力、自発的な通知を対象にするか。
- 対話相手の役割や人格を誰が設定・変更するか。
- 好感度を利用者が閲覧、訂正、初期化できる機能を提供するか。
- 好感度以外の育成パラメーターや、パラメーターによるツール解禁を導入するか。
